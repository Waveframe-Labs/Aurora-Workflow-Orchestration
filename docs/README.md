# AWO v2 Documentation Directory

This directory contains **supplemental documentation** to support readers, contributors, and implementers working with AWO v2.0.0. These materials provide clarification, onboarding, and common reference points that complement — but do not replace — the normative specification.

---

## Contents

- `FAQ.md`  
  Answers frequent questions about AWO’s purpose, workflow, constraints, and interpretations.

- `ONBOARDING_GUIDE.md`  
  A structured orientation document outlining how new contributors should enter and navigate the AWO system.

---

## Purpose

The documents in this directory:

- expand on concepts defined in the root specification  
- help new contributors quickly understand the workflow  
- provide human-readable context without introducing new rules  

They are intentionally explanatory rather than prescriptive.

## Normative Status

**Non-normative.**  
These documents do not define constraints, enforce requirements, or introduce authoritative rules. They exist to improve clarity and usability. The normative specification is located in the root of the repository.
