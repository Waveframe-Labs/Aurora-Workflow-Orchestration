# AWO v2 Examples

This directory contains **non-normative reference examples** demonstrating how AWO v2 artifacts are instantiated in practice. These files illustrate correct structure and minimal required fields but do not define rules or modify the AWO specification.

---

## Contents

- `awo.initiation.example.json`  
  A minimal, schema-aligned initiation record used to illustrate the required fields for activating an AWO workflow instance.

## Purpose

The examples in this directory are meant to:

- provide implementers with concrete template artifacts  
- demonstrate minimal compliance patterns  
- reduce ambiguity when translating the AWO specification into operational workflows  

These examples intentionally avoid optional metadata for clarity.
